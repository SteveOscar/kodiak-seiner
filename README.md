# Kodiak Seiner

A 3D browser game about Alaskan salmon purse seining around a real-geography Kodiak Island. Find schools of salmon by
their jumpers, let the skiff go, lay the seine around them, purse up, haul with the power block, brail the catch and
deliver it to a tender. Between sets, explore the island's bays, villages, capes, streams and mountains by boat and on
foot.

Work in progress. Built with three.js and Vite; all art is procedural.

```
npm install
npm run dev      # play at the printed URL
npm test         # unit tests
npm run build    # production build in dist/
```
